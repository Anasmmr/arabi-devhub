# Google Developer Hub

Build a complete, modern, responsive website for an Arabic-first Google Developer community called “Google Developer”.

The website should feel like a premium developer community platform that combines learning, community, gamification, achievements, certificates, and developer identity.

The design should be modern, clean, interactive, motivating, and fun — but still professional. The goal is to create a website that feels more engaging and visually impressive than the current Google Developer website in Malaysia.

1. Language & Direction

The primary language must be Arabic.

Use a proper RTL (Right-to-Left) layout.

Arabic typography should be modern, clean, and highly readable.

The website is mainly targeting developers in the Middle East, while remaining suitable for users across the Arab world.

All UI elements, buttons, navigation, cards, dashboards, and messages should support Arabic naturally.

The design should feel culturally appropriate for a modern Middle Eastern developer community.

Design the entire website mobile-first.

Mobile phones

iPads/tablets

Desktop screens

Buttons must be touch-friendly.

AI: 50 Points

+50 Points

If a user has already received points for a course or learning path, they should not receive the same points again.
